## V1 尚未实现或尚未验证

- 应用内相机、连续拍摄和拍后预览（用户手册 6–7，操作指南 5）：使用手机现有相机拍照后文件导入。
- 透视/倾斜校正、无边框或合并单元格处理、跨行合并表头、表格结构编辑：当前只接收完整规整网格，不能将通用动态 Schema 等同于任意纸张布局识别。
- 相似重复自动匹配、已保存场景模板、自动业务字段推断：未实现；保留通用配置和精确比较。
- 手写质量（用户手册 FAQ，操作指南 12）、真实模糊/裁切照片（T05/T06）：有保守拒绝和低可靠机制，尚无真实材料准确率证据。印刷识别也尚未在本轮设备上执行。
- 系统选择器、长期 URI 权限经强停/设备重启后的恢复、WorkManager 实际系统调度、手机上的完整闭环（T02/T24/T25/最终场景）：本轮 V2055A / API 34 可连接，但 APK 安装返回 `INSTALL_FAILED_ABORTED: User rejected permissions`。
- Excel/WPS 实际打开（T26/T28/T29）：ZIP/XML 结构及逐 Cell 值独立解析通过，未执行这些应用的打开验收。
- 真实质量基准（T30–T33）：有 800 Cell 合成候选基准，不能将其 100% 检出率解释为真实纸张效果。

## 测试基线应补充的口径

当前 fixture 预置 16 个 Cell 异常目标、2 个疑似重复组及 1 个异结构页，共 19 个真实异常目标。
系统产生 23 条底层 Issue，聚合为 19 个 ReviewItem；复核率为 19/800 = 2.375%。
其中“真实”指预置标签，复核动作来自预置答案；不是自然采集的真实异常，也不表示 19 次点击即可完成全部操作。
首次规则配置、来源检查、重复组的逐行对照不等于单 Cell 操作成本；应另采真实人工用时。
建议后续保留这套回归基准，同时增加经过授权脱敏的真实照片与独立人工标注集，报告分层、漏检和误报原因。
