## 阶段 2 设计：动态结构与候选存储

新增四张表。每个任务一个动态 Schema；字段按 ID 关联，显示顺序独立于原始列序。
复合外键防止 Row / Cell / Field / SourceDocument 串任务或串 Schema。来源删除级联删除对应行和 Cell，不影响原图。
一页候选在一个事务内替换；保留同来源同原行列的稳定 ID。新的 raw 是这次识别的原始候选，normalized / confirmed 均为空。
重复执行不追加重复行；如果已有人工确认、无法确认或排除记录，必须显式允许丢弃人工工作，不能静默覆盖。
页面表头与来源列身份不一致时拒绝入库，后续处理层会将此结果持久化为可处理的页面问题。
候选完成仅保持 PROCESSING，必须经过后续质量检查才可能进入可导出状态。
本段只新增真实可测试的数据能力，用户界面随后接入，不能视为 V1 已完成。
